#### IaaS (Infrastructure as a Service)
Аренда сервера или виртуальной машины в дата-центре<br>
Управление ОС, приложениями, данными<br>
Примеры в этой работе: Virtual Machine, Azure Storage

#### PaaS (Platform as a Service)
Аренда готовой площадки для разработки и запуска приложений<br>
Управление кодом и данными приложения<br>
Примеры в этой работе: Azure SQL Database, App Service, Azure Data Factory, SQL Data Warehouse

#### SaaS (Software as a Service)
Готовое приложение, доступное через браузер<br>
Управление только своими данными и настройками<br>
Примеры в этой работе: Visual Studio Team Services

По аналогии с 1 лабораторной и файлом `example` заполним столбцы:<br>
`IT Tower` - верхний уровень иерархии, "к какой категории капитальных затрат это относится?"<br>
`Service Family` - группировка по функциональному назначению, "какую бизнес-задачу решает сервис?"<br>
`Service Type` - название конкретного продукта от провайдера<br>
`Service Sub Type` - "внутри продукта за какую именно часть мы платим?"<br>
`Service Usage Type` - уточняет конкретную метрику<br>
